# Aaj Kiya Banoan? (آج کیا بناؤں؟) 🍲

A personalized Pakistani meal recommendation & nutrition tracking web app built to solve the eternal household dilemma: **"Aaj kya banaun?"** ("What should I cook today?").

---

## 💡 The Problem
In almost every Desi household, the daily question *"Aaj kya banaun?"* sparks endless debate — especially when catering to picky eaters while striving to maintain a balanced, nutritious diet.

## ✨ The Solution
**Aaj Kiya Banoan** is designed specifically for Desi families:
- **Intelligent Meal Recommendations**: Ranks traditional Pakistani dishes (Biryani, Pulao, Karahi, Daal, Sabzi, etc.) based on family preferences, recent meal history, and variety.
- **Nutritional Awareness**: Estimates calories, macronutrients (proteins, carbs, fats), and key micronutrients (iron, zinc, magnesium) tailored to authentic Pakistani cooking.
- **Smart Pairing & Complements**: Suggests healthy pairings (salads, raita, dry fruits, seasonal fruits) to round out daily nutritional gaps.
- **Mom-Friendly, Mobile-First UI**: Simple, intuitive bilingual design (English with Urdu dish titles in brackets) built for seamless daily mobile use.

---

## 🛠 Planned Tech Stack
- **Frontend**: Next.js, React, TypeScript
- **Styling**: Vanilla CSS / Modern UI
- **Database & Auth**: Supabase
- **Recommendation Engine**: Rule-based scoring algorithm balancing preference, nutrition gaps, and repetition limits
